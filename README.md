# CVT Detection Project

On-device context-aware AI service for detecting teen financial coercion by combining message pressure signals, transfer events, and risk scoring.

## Repositories / Modules

- `app/`: Flutter app for chat simulation, transfer flow, risk alerts, and guardian intervention UX
- `backend/`: Backend API server for risk scoring, guardian alerts, and event logging
- `model/`: Rule-based trigger, pressure scoring model, and risk scoring prototype
- `docs/`: Project documentation and presentation materials
